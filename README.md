# ZubairRay Connect Buttons

A lightweight and privacy-friendly WordPress plugin that adds floating contact buttons for WhatsApp, Email, Phone, Telegram, Messenger, and Custom Links.

## Features

* WhatsApp Button
* Email Button
* Phone Button
* Telegram Button
* Messenger Button
* Custom Link Button
* Smart Visibility Rules
* Mobile & Desktop Controls
* Custom Colors & Labels
* Lightweight & Fast
* Privacy Friendly
* Translation Ready

## Perfect For

* Business Websites
* Agency Websites
* Freelancers
* Local Businesses
* Landing Pages
* WooCommerce Stores
