Add floating WhatsApp, Email, Phone, Telegram, Messenger, and custom contact buttons to your WordPress website.

== Description ==

ZubairRay Connect Buttons lets you add floating WhatsApp, Email, Phone, Telegram, Messenger, and Custom Link buttons to your WordPress website. Customize button labels, colors, position, and visibility rules for desktop, mobile, logged-in users, and guests.

Whether you need a floating WhatsApp button, contact button, phone call button, Telegram button, or Messenger button, ZubairRay Connect Buttons provides a lightweight and privacy-friendly solution for WordPress websites.

== Installation ==

1. Upload the zubairray-connect-buttons folder to the /wp-content/plugins/ directory.
2. Activate the plugin through the Plugins screen in WordPress.
3. Go to ZubairRay Connect Buttons in the WordPress admin sidebar.
4. Configure your contact channels and visibility rules.
5. Save changes.

== Frequently Asked Questions ==

= Can I show only one button? =

Yes. Leave any channel value empty to hide that button.

= Can I hide buttons on mobile or for logged-in users? =

Yes. Use Smart Visibility Rules to show or hide buttons by device (desktop/mobile) and audience (logged-in users/guests).

= Which contact channels are supported? =

Email, WhatsApp, Phone, Telegram, Messenger, and Custom Link.

= Can I customize button colors and labels? =

Yes. Each contact button can be customized from the plugin settings page.

= Does this plugin load external files? =

No. The plugin uses local CSS and bundled inline SVG icons. External links such as WhatsApp, Telegram, Messenger, or Email only open when a visitor clicks a button.

= Does this plugin collect personal data? =

No. The plugin does not track visitors, call external APIs, or collect personal data.
